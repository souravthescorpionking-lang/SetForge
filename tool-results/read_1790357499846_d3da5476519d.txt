     6→     6→## Project Overview
     7→     7→- **App name**: SetForge (original brand; not FitNotes)
     8→     8→- **What**: Production-grade multi-user workout tracker PWA. Shared DB, login/logout, full data isolation per user.
     9→     9→- **Visible route**: ONLY `/` (per sandbox constraint). All "pages" are client-side hash routes (`#/today`, `#/exercises`, etc.) inside the single page. API lives under `/api/*`.
    10→    10→- **Stack (sandbox-fixed)**: Next.js 16 App Router, TypeScript strict, Prisma (SQLite in sandbox; schema is provider-portable), Tailwind 4 + shadcn/ui, TanStack Query, Zustand, Recharts, dnd-kit, framer-motion, Zod 4, sonner.
    11→    11→- **Design system**: Dark-first athletic theme. Primary = vivid orange (#f97316 family) on zinc neutrals. NO blue/indigo as UI primary. Category colours are data (varied hues allowed). Rounded-2xl cards, sticky bottom nav on mobile (acts as footer), left sidebar on desktop.
    12→    12→
    13→    13→## Architecture (binding conventions for all agents)
    14→    14→- **IDs**: UUID v7 generated app-side (`src/lib/uuid7.ts` → `uuid7()`).
    15→    15→- **Multi-tenancy**: every domain table has `userId`; every query filters by it; mutations assert ownership.
    16→    16→- **Auth**: custom credentials auth. scrypt password hashing (`src/server/auth.ts`). Session = opaque token in `Session` table + httpOnly cookie `sf_session`. API guard: `requireUser(req)` in `src/server/http.ts`.
    17→    17→- **API style**: JSON, Zod-validated. Errors: `{ error: { code, message, details? } }`. Success: direct JSON body.
    18→    18→- **Client data layer**: `src/lib/client/api.ts` — typed functions for EVERY endpoint. Feature components must use these + TanStack Query hooks (`src/lib/client/hooks.ts` if present).
    19→    19→- **Feature folders**: `src/features/<domain>/**` — each agent owns ONLY its assigned folder. Shared UI: `src/components/**` (owner: main agent).
    20→    20→- **Date handling**: workout `date` stored as UTC-midnight ISO string in JSON (`2025-01-05T00:00:00.000Z`). Client uses `src/lib/client/format.ts` helpers.
    21→    21→- **Sets fields by exercise type** (`src/lib/constants.ts` `FIELDS_BY_TYPE`).
    22→    22→- **PR recompute** after every set mutation (same request).
