   160→   160→
   161→   161→#### `WorkoutContext` (`context/WorkoutContext.tsx`)
   162→   162→
   163→   163→Central in-memory + AsyncStorage store. Wraps the entire app.
   164→   164→
   165→   165→Exposed state slices:
   166→   166→
   167→   167→| State | Type | Purpose |
   168→   168→|---|---|---|
   169→   169→| `workouts` | `SavedWorkout[]` | User-saved single workouts |
   170→   170→| `userPrograms` | `UserProgram[]` | Seed programs (Jacklete, Legacy Bro Split) + user-created programs |
   171→   171→| `userOnDemand` | `UserOnDemand[]` | User-saved on-demand sessions |
   172→   172→| `activeProgram` | `ActiveProgramState \| null` | `{ programId, completedSessions }` — currently active program |
   173→   173→| `currentProgramId` | `string \| null` | Selected program in builder flows |
   174→   174→| `buildExercises` | `BuildExercise[]` | Workout builder draft state (sets, reps, tempo, intensifier, series grouping) |

   176→   176→
   177→   177→Key actions:
   178→   178→
   179→   179→```ts
   180→   180→setActiveProgram(programId)        // start a program from day 1
   181→   181→advanceActiveDay()                  // increment completedSessions
   182→   182→clearActiveProgram()
   183→   183→addWorkout(w) / removeWorkout(id)
   184→   184→addUserProgram(p) / patchUserProgram(id, changes) / removeUserProgram(id)
   185→   185→addBuildExercises(pending) / reorderSeriesGroups(order) / updateBuildSet(...) / clearBuild()
   186→   186→addUserOnDemand(u) / removeUserOnDemand(id)
   187→   187→setPendingAction(list, mode, meta) / clearPendingExercises()
   188→   188→```
   189→   189→
   190→   190→Persistence keys (AsyncStorage):
   191→   191→| Key | Payload |
   192→   192→|---|---|
   193→   193→| `stndrd_active_program_v1` | `ActiveProgramState` |
   194→   194→| `stndrd_jacklete_seeded_v1` | seed flag for Jacklete logs |
   195→   195→| `stndrd_logs_seeded_v1` | seed flag for scheduled workouts |
   196→   196→
   197→   197→Day progression for active program:
   198→   198→```
   199→   199→workoutDays   = program.days.filter(d => d.type === "workout")
   200→   200→totalSessions = workoutDays.length * program.weeks
   201→   201→currentDay    = workoutDays[completedSessions % workoutDays.length]
   202→   202→weekNumber    = Math.floor(completedSessions / workoutDays.length) + 1
   203→   203→dayNumber     = completedSessions + 1
   204→   204→// Rest days excluded from counter; program auto-clears when complete.
   205→   205→```
